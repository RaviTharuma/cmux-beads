# Glossary

| Term | Meaning |
|------|---------|
| **cmux-beads** | cmux sidebar plugin for Beads (`bd`) — Kanban GUI + live status |
| **cmux** | Terminal / agent workspace UI this plugin extends |
| **Beads** (`bd`) | Durable agent task tracker (issues, deps, handoff) |
| **Kanban** | Board view of Beads issues in the cmux sidebar |
| **DEV-001** | Canonical coding host label |
